# Costs

| Item | Cost | Notes |
|---|---|---|
| GitHub Actions | £0 | Public repositories get free standard runners. ~96 collect runs a day at ~2–4 min each |
| GitHub Pages | £0 | Public site |
| ATS APIs (Greenhouse, Lever, Ashby, SmartRecruiters, Workable, Recruitee, Personio) | £0 | Public, no key |
| Contracts Finder | £0 | Open government data |
| Reed API | £0 | Free key. Capped at 900 requests/day in the code |
| Jooble API | £0 | Free key, 100 requests/day. Capped at 60/day in the code |
| AI | £0 | Not used. Labelling is rule-based with quotes from the advert |
| Email | £0 now | Off. Needs an SMTP provider if wanted (many have a free tier) |

**Total today: £0 a month.**

Trade-off of the free setup: the repository and site are public. The data is public job adverts plus one test account; no secrets are in it.
If you want it private later: GitHub Pro (about $4 a month) gives private Pages, with 3,000 Actions minutes a month,
which is not enough for a 15-minute schedule; you'd move to hourly checks or pay for minutes.
